# 项目环境

## 环境要求

| 项 | 要求 | 说明 |
|----|------|------|
| Xcode | 15 及以上 | 需要 iOS 14 SDK |
| 最低部署目标 | iOS 14.0 | 涂鸦 7.11 起 UI 业务包最低支持 iOS 14，全工程统一 14.0 |
| CocoaPods | 1.13+ | 源：cdn.cocoapods.org + tuya/tuya-pod-specs |
| XcodeGen | 可选 | 仅修改 `project.yml` 后需要重新 `xcodegen generate` |
| 真机 | 必须 | SDK 未提供 arm64 模拟器切片，Apple Silicon 无法跑模拟器 |

## 依赖与版本（Podfile.lock 对齐）

| Pod | 版本 | 来源 |
|-----|------|------|
| ThingSmartCryption | 5.0.0 | 涂鸦 IoT 平台下载的 ios_core_sdk（AppKey 绑定，`:path => './TuyaSDK/ios_core_sdk'`） |
| ThingSmartHomeKit | 7.11.0.1 | 由 AppIOSBase podspec 依赖带出 |
| ThingSmartBusinessExtensionKit | 7.11.0.1 | Podfile 显式声明 `~> 7.11.0` |
| ThingSmartLockKit | 7.11.0.3 | Podfile 固定版本（7.11 线最新） |
| ThingModuleServices | 4.76.6 | **固定版本**，勿升级，见《常见错误与排查》 |
| AppIOSBase | 0.2.0 | `:git => 'https://github.com/liuhepan-web/AppIOSBase.git', :tag => '0.2.0'`（登录/家庭/设备列表/个人中心，无业务包） |

## AppIOSBase（自研基础库）

- 注册 / 登录 / 家庭列表与切换 / 设备列表 / 个人中心，无任何面板业务包。
- 设备点击通过 `Base.devicePanelHandler` 钩子回调宿主，映射到本工程的原生锁面板（BLE / Wi-Fi / 视频 / 拍照）。
- 升级方式：改 Podfile 里的 `:tag` 后 `pod update AppIOSBase`。

## 构建工具链

- 工程由 XcodeGen 从 `project.yml` 生成，`IPHONEOS_DEPLOYMENT_TARGET`、签名等基础设置都在 `project.yml` 里改。
- Podfile 的 `post_install` 统一把所有 pod 的部署目标压平到 14.0，并对模拟器排除 arm64。

# 接入步骤

从零 clone 到真机运行的完整流程。

## 1. 前置准备

1. 涂鸦 IoT 平台创建 iOS App SDK（Bundle ID 必须与工程一致，默认 `com.lock.set`），拿到 AppKey / AppSecret。
2. 在该 App 的「集成资料」里下载 **ios_core_sdk** 安全组件包（AppKey 绑定生成，不能混用其他 App 的）。
3. 平台证书里配置调试机的 SHA256（或使用开发证书默认配置）。

## 2. 配置本地凭证

```bash
cd LockDemo/App
cp LocalSecrets.example.plist LocalSecrets.plist
# 编辑 LocalSecrets.plist，填入 AppKey / AppSecret
```

该文件已被 `.gitignore` 排除，**永远不要提交**。

## 3. 放置安全 SDK

解压第 1 步下载的 ios_core_sdk，覆盖到工程根目录：

```
TuyaSDK/ios_core_sdk/        # 目录内应包含 ThingSmartCryption.podspec
```

## 4. 安装依赖

```bash
pod install --repo-update
```

- 首次安装或升级涂鸦大版本后必须 `--repo-update`（tuya-pod-specs 源更新）。
- 如果报依赖快照冲突，改用 `pod update <冲突的 Pod>`，不要只 `pod install`。

## 5. 打开工程

```bash
open LockDemo.xcworkspace     # 必须用 workspace，不能用 xcodeproj
```

如果改过 `project.yml`：先 `xcodegen generate` 再重新 `pod install`。

## 6. 签名与运行

1. Xcode → Settings → Accounts 登录开发者账号。
2. Target LockDemo → Signing & Capabilities 选择自己的 Team。
3. 插真机 Run（不支持 Apple Silicon 模拟器，见《常见错误与排查》）。

## 7. 验证

启动后依次走通：登录 → 家庭列表（左上角「家庭」可切换/创建）→ 设备列表 → 点击门锁进入对应原生面板（BLE / Wi-Fi / 视频 / 拍照按品类自动路由）。

# 日常典型问题

门锁业务高频问题沉淀（工单 / 联调常见）。

## 配网类

- **EZ / AP 配网失败**：手机必须与设备同一 2.4G Wi-Fi（5G 不支持）；AP 模式热点前缀在涂鸦平台配置里（本工程为 `AAA|BBB`），换自定义前缀要同步平台配置。
- **BLE 配网搜不到设备**：门锁未进入配网模式、手机蓝牙权限未开、或锁已在其他账号下（需先解绑）。
- **配网超时**：优先看失败回调里的具体 errorCode，区分「Wi-Fi 密码错误」「云端激活失败」「设备侧超时」。

## 临时密码类

- **在线临时密码**：4-15 位，24 小时有效；周期参数统一传字符串
  `[{"allDay":true,"effectiveTime":0,"invalidTime":0,"workingDay":127}]`（与 Android FastJSON 序列化一致）。
- **视频锁离线密码**：云端生成，7 天有效、可多次使用；**拍照锁**离线密码走在线密码列表管理，两者接口不同。
- **时间单位易错**：拍照锁在线密码传毫秒，视频锁与离线密码传秒——服务层已做归一化，新加接口时注意别混。
- **密码 SN**：视频锁 SN 从设备 schema 的 `unlock_temporary` / `temporary_password_creat` 解析 dpId，解析失败回退 `69`。

## 成员管理类

- Wi-Fi 锁密码 SN 绑定成员；视频锁面板内管理成员。
- BLE 锁分 Pro（邀请制成员列表）与标准（仅当前成员）两套接口，按设备产品型号路由。

## 面板与设备类

- **设备列表为空**：先确认 App 内已选家庭（左上角「家庭」切换），设备挂在家庭下。
- **点击设备没反应**：查品类路由，只支持 BLE / Wi-Fi / 视频 / 拍照门锁；其他品类弹不支持提示。
- **视频预览黑屏**：确认真机 + IPC SDK（`thingsmart-ipcsdk 7.11.3`）完整集成；模拟器不支持 P2P。
- **远程开锁失败**：锁在线状态优先；离线锁只能走 BLE 本地操作。

## 版本对齐

- iOS 与 Android 双端保持同版本线（当前均为 7.11.x），临时密码等接口参数双端一致，排查时对照 Android 侧 `AppAndroidLockAiDemo` 的实现最有效。
